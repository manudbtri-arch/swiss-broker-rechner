# 🇨🇭 Schweizer Broker-, Depotkosten- & Vanguard All-World Rechner

Interaktive Web-App zum Vergleich von Schweizer Brokern, Neobanken (neon, Yuh), Staats-/Grossbanken (ZKB, PostFinance, Raiffeisen, UBS) und Online-Brokern (Saxo, Swissquote, IBKR, VIAC) – inklusive Simulation für den **Vanguard FTSE All-World UCITS ETF (USD) Accumulating (`IE00BK5BQT80`)**.

## Features
- **Gestaffelter Investitions-Plan:** Start-Investition (z. B. CHF 50'000) + monatliche Tranchen (z. B. CHF 5'000/Mt.) bis das Gesamtkapital investiert ist.
- **Vollständige Schweizer Kostenstruktur:** Einmal-Courtagen, Sparplan-Rabatte, laufende Depotgebühren, Währungswechsel (FX) und eidg. Stempelsteuer (0.075% CH / 0.15% Ausland).
- **Vanguard FTSE All-World (Acc) Wachstums-Simulation:** Zeigt live über 1 bis 20 Jahre, wie sich Zinseszins und mitwachsende prozentuale Bank-Depotgebühren auf das Endvermögen auswirken.
- **Dark / Light Mode** Umschalter integriert.
